# KOFFRA — Identité visuelle

## Direction
Identité sobre, professionnelle, technologique et rassurante. Le bleu est dominant ; le vert sert d'accent. Logo approuvé dans son principe : symbole circulaire dynamique/rayonnant et lettre K, création originale, sans copie de TEHORA.

## Palette de travail
- Bleu principal : `#123B70`
- Bleu profond : `#0B2545`
- Vert accent : `#79C143`
- Blanc : `#FFFFFF`
- Gris clair : `#F3F6FA`
- Texte : `#182433`

Le bleu exact du logo HKF STAFF n'a pas été mesuré de façon certaine. Les valeurs ci-dessus sont une base de travail et devront être remplacées par le code officiellement échantillonné si le logo source est fourni.

## UI
- Fond clair majoritaire, surfaces blanches, bordures discrètes.
- Bleu pour navigation, actions principales et titres.
- Vert uniquement pour états positifs et petits accents.
- Typographie sans-serif moderne (Inter ou système).
- Cartes sobres, coins modérés, espaces généreux.
- Contraste WCAG AA minimum ; ne pas utiliser le vert seul pour transmettre un état.
- Responsive mobile-first, navigation latérale sur desktop et navigation compacte sur mobile.

## Logo
Voir `branding/logo/`. SVG natifs à utiliser en priorité sur le web. PNG pour PWA et usages raster. ICO pour favicon. JPG/JPEG sur fond blanc.
